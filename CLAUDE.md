## Overview

This is a Jekyll blog using the [no-style-please](https://github.com/riggraz/no-style-please) theme, deployed via GitHub Pages. The blog is in Korean (ko-KR) with Seoul timezone.

## Common Commands

```bash
# Install dependencies
bundle install

# Start local development server at http://localhost:4000
make up

# Create a new post (uses post_template.md)
make new title="My New Post"

# Generate tag pages from post front matter
make tag

# Generate category pages from post front matter
make cat
```

## Architecture

- **Posts**: Markdown files in `_posts/` with format `YYYY-MM-DD-title-slug.md`
- **Front matter**: Each post requires `layout: post`, `category`, and `tags`
- **Tag/Category pages**: Auto-generated by Ruby scripts in `scripts/` that scan posts and create pages in `_tag_pages/` and `categories/`
- **Layouts**: Custom layouts in `_layouts/` (archive, category, default, home, page, post, tag)
- **Menu configuration**: Edit `_data/menu.yml` to customize navigation

## Deployment

GitHub Actions workflow (`.github/workflows/jekyll.yml`) runs on push to master:
1. Generates tag and category pages via Ruby scripts
2. Builds with `bundle exec jekyll build`
3. Deploys to GitHub Pages
